# 7 Building Innovation

Socle du site institutionnel de 7 Building Innovation, construit avec Next.js, TypeScript et Tailwind CSS.

## Commandes

- `npm run dev` : démarrer le serveur de développement ;
- `npm run lint` : vérifier le code ;
- `npm run build` : générer le build de production.

Les informations de l’entreprise et les services sont centralisés dans `src/data/`. Les coordonnées, réseaux sociaux et projets restent volontairement vides jusqu’à validation de contenus réels.
